# 「活动回顾/会议回顾」体裁模板

> 来源：从艾名医学公众号三篇已发稿（进博会回顾、双会回顾、生物样本库论坛回顾）逆向提取，并经一次完整写作-主编修订循环验证。写同类稿件时按此模板组织，再叠加 `brand-assets/` 中目标账号的个性化档案。

## 一、标题公式

```
回顾词丨/｜ + 公司动作句，+ 价值亮点句
```

- 回顾词：「展会回顾｜」或「会议回顾丨」（竖线样式随账号习惯，两可）。
- 动作句：亮相/出席/签约 + 活动名或活动简称。
- 亮点句：本次参与最有含金量的一点（技术获关注、平台签约、标准引领等），可带「」标口号或方案名。

实证：
- 「展会回顾｜艾名医学亮相第九届进博会，"AI＋类器官"技术获广泛关注！」
- 「会议回顾丨双城联动，艾名医学「AI＋类器官」药物研发整体解决方案亮相药物毒理学年会与SAPA医药产业大会」

可选：标题下单独一行时间标注（`11月21日 · 上海`），多活动稿件更常用。

## 二、导语段：固定四步

```
活动硬事实（何时+何地+何活动全称）
→ 活动规格背书（主办/承办方、级别、主题、规模数字——只用可证实信息）
→ 公司身份标准句（从品牌资产库原样取用）
→ 本次动作概述（做了什么：受邀出席/作报告/签约/设展）
```

规格背书的纪律：断言式规格表述（"重要的国际平台"）若无事实支撑会被编辑删改——改用功能描述（"组织X家头部药企、搭建X-Y产业对话通道"）来呈现规格；机构角色严格按素材（承办≠主办）。

## 三、正文：按场景切小标题段

小标题 = 场景概括短语，常见模式：「人物/场合+动作+收益点」，如「中新嘉宾莅临，共探产业合作机遇」「现场签约：从类器官走向器官芯片」「行业观察：NAMs站上舞台中央」。

**段内逻辑**（每段内部顺序）：

```
场景事实（时间/场次/人物/名目）
→ 公司动作与具体内容
→ 反响与成果（交流、意向、共鸣、签约）
→ 意义提升一句（升格到行业/趋势层面）
```

可选的"增味"手法：在报告中嵌入一个具体案例细节（如某药企肝毒性在动物模型与类器官模型上的相反结果），比抽象表述更有说服力——每篇最多一处。

## 四、主线纪律（单事件稿）

- 全文只认**一个实质新闻点**（签约/报告/发布），其余一切内容的功能是烘托该新闻点的含金量。
- 议程、嘉宾阵容**不逐条罗列**：用1-2句概括阵容层级与议题面即可。主编实测反馈："聚力创新"式背景段会被整段删除——场景信息压缩进导语即可。
- 单事件稿全文 1000–1300 字；导语约200字；核心段400–500字；其余段落100–150字。

## 五、合作/协议内容的转写纪律

- 合同用语不入正文：无"甲方/乙方"，用公司名或"双方/合作方"。
- 条款改写成"一是…二是…三是…四是…"简列，每条一个小标题式短语（模型共建/评价服务/联合申报/证据链验证）+ 一两句叙述。
- 签约对方是否点名：默认点名（主编实证口径："签约方要在第二段写明"），除非用户明确要求匿名。
- 政策类内容（监管试点、联合申报）可前置：在导语或签约段开头以"在X政策指引下，双方完成签约"框架呈现，并在核心段给细节、行业观察段呼应前景——一篇内出现2-3次不嫌多，这是PR稿提升含金量的常规手段。

## 六、结语固定动作

```
感谢主办方/组织方 + 未来表态句（"未来，艾名/我司将继续深耕X，推动Y……"）
+ 呼应活动主题的金句收尾
```

## 七、完整段落骨架（单事件签约稿示例）

```
标题（回顾词丨+动作句+亮点句）
[时间标注行：11月21日 · 上海]

导语段：硬事实 → 规格背书 → 身份标准句 → 动作概述（可含政策框架句）
[配图：活动全景]

## 现场签约：{从A走向B / 合作再升级}
[配图：签约瞬间]
引子：在既有合作基础上范围拓展（点名对方公司）
一是…/二是…/三是…/四是…（协议内容转写）
意义句收束

## 行业观察：{趋势词}站上舞台中央 / 或并入上段
趋势判断句 + 公司近期活动轨迹（连续性背书）+ 本次动作定位

## 结语
感谢 + 表态 + 主题呼应
```

## 八、发布前检查单

- [ ] 标题符合公式
- [ ] 导语四步齐全、规格表述全部可证实
- [ ] 实质新闻点唯一且给足篇幅
- [ ] 无合同用语（甲方/乙方）；点名口径与拍板一致
- [ ] 公司身份标准句与资产库一致（原样复用）
- [ ] 政策表述有素材依据、措辞未虚构因果
- [ ] 结语含"感谢+表态+主题呼应"
- [ ] 图片位已标注、素材已向用户索取
