# wechat-pr-writer

企业/机构微信公众号消息类稿件（活动回顾、会议回顾、签约、成果发布、参展参会报道等 PR 新闻稿）的事实整理与写作工作流 skill。

**核心理念：推文是品牌资产** —— 已发文章是风格权威与标准句来源，发布后回收终稿反哺风格库。

## 工作流

```
乱素材 → ①事实清单（只辑录）→ ②风格对标 → ③对话拍板 → ④分段框架 → ⑤正文初稿 → ⑥修订循环 → ⑦终稿回收学习
```

## 目录

- `SKILL.md` — skill 主文件（安装后由 agent 加载）
- `references/recap-genre-template.md` — 「活动回顾」体裁模板
- `references/brand-assets/` — 各账号品牌资产档案（风格笔记、标准句、编辑偏好、已发稿存档）

## 安装

将本目录复制到 skills 目录（如 `~/.agents/skills/`）即可被支持 skill 的 agent 自动发现和调用。
